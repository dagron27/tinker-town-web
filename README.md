# Tinker Town (Web Build)

This repository hosts the public WebGL release of **Tinker Town**, playable in browser via GitHub Pages.

- **Game**: Tinker Town
- **Target Audience**: Children ages 6–8 (neurodivergent & ADHD-friendly design)
- **Live Playable Link**: https://dagron27.github.io/Tinker-Town-Web/
- **Engine**: Godot 4.7.2 (Single-Threaded Compatibility WebGL export)

---
*Note: This repository contains only compiled web distribution artifacts (`index.html`, `index.pck`, `index.wasm`). Source code and project development are maintained in the private core repository.*
